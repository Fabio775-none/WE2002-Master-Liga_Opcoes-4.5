# WE2002-Master-Liga_Opcoes-4.5
Editor de Master Liga do Winning Eleven 2002 (PS1), desenvolvido em C# com Windows Forms por Fabio FJA. Permite modificar os créditos de 0 a 9.999, configurar até 255 contratações, ler valores diretamente do arquivo BIN e restaurar as configurações originais por meio de edição de offsets binários.
